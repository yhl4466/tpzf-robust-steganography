# TPZF 工具箱

> 在浏览器里把一张秘密图藏进另一张普通图。零后端，零依赖，图片不上传。

一个纯前端的图像隐写工具：选一张载体图（用来伪装的普通照片）和一张秘密图（要藏起来的内容），
工具会把秘密图写进载体图的像素里，生成一张肉眼看不出区别的隐写图；对方用同一个工具的"提取"页
上传这张图，就能还原出秘密图。

## 特性

- 🖼️ **纯前端**：所有运算在浏览器本地完成，图片不会离开设备
- 🛡️ **抗压缩**：轻度 JPEG 压缩后仍可还原
- 🔧 **抗损坏**：局部损坏 25% 内可完整恢复
- 🎨 **载体一键生成**：没有合适的载体图？工具用分形噪声帮你生成一张纹理充足、无压缩历史的理想载体
  （五种风格，支持 1024² / 2048² / 4096² / 16:9 / 4K，最大 8192×8192，生成过程有进度条不卡界面）
- 📱 **手机友好**：秘密图过大时自动缩放 + 自适应 JPEG 质量（容量富余更清晰、紧张自动降质），
  不再直接报"放不下"；提供灰度模式与"高清优先 / 均衡 / 容量优先"三档，
  窄屏设备默认使用容量最大的紧凑档
- 📊 **跨平台**：支持现代桌面与移动浏览器，也可以直接双击本地文件打开

## 快速开始

### 使用方式一：在线访问（GitHub Pages）

访问 https://yhl4466.github.io/tpzf-robust-steganography/ 

### 使用方式二：本地运行

1. 下载本项目（`git clone` 或下载 ZIP 并解压）
2. 双击 `index.html`，用浏览器打开
3. 无需服务器，无需安装任何东西

## 使用方法

1. 打开"嵌入"页，上传载体图（用于伪装的图）和秘密图（要隐藏的图）
   —— 没有合适的载体图？嵌入页支持一键生成（分形噪声合成，纹理充足且无压缩历史）
   —— 秘密图偏大时页面会**在上传后立刻**告诉你"已自动缩至 W×H"，并在装不下时给出三条建议
2. 点击"开始嵌入"，完成后下载隐写图（PNG）
3. 通过"原图/文件"方式发送给对方
4. 对方打开"提取"页，上传隐写图，即可还原秘密图

> 手机相册照片做载体时，可用纹理区往往很少（很多天空 / 水面）。此时可在"高级设置"里开启
> **灰度模式**（秘密图体积实测降到彩色的 66%~93%，容量多 10%~50%，同样体积下可用更高的
> JPEG 质量），或把"画质 vs 容量"改成"容量优先"。

## ⚠️ 重要提示

- **必须用"原图/文件"方式传输**：微信/QQ 的普通发送会触发平台压缩（长边压到 1080 像素并重新
  JPEG 编码），导致秘密图无法还原。请用微信"发送原图"、QQ 发送文件、邮件附件、云盘或 U 盘。
- **载体图建议用纹理丰富的照片**：树叶、人群、砖墙等；避免纯色、大面积天空、几何矢量图，
  这类图可用区域少，能藏的数据量小且更容易被压缩破坏。
- 不想挑图？用工具一键生成。

## 技术细节

- 核心方法：DCT 差分符号调制（8×8 正交 DCT 的系数对符号）+ 系统化 Reed–Solomon 纠删码
  （GF(2^16)）+ 双导频几何标定与网格相位重同步
- 抗损坏能力（标准档）：局部遮挡 25% 内稳定恢复，中心区域遮挡 30~40% 常可恢复，
  理论上限为 50%（N = 2K，受承载块空间分布影响）
- 完整技术报告见 [tech.html](tech.html)
- 自动化测试：在浏览器中打开 `dev-test-suite.html` 可运行 36 项端到端用例

## 已知限制

- 局部损坏 > 50% 无法恢复（N = 2K 的数学上限）
- 平台强压缩（微信/QQ 普通发送）会导致完全失效
- 1~7 px 全局平移暂不支持（相位搜索粒度 8 px）
- 纯噪声载体 + 缩放的组合存在 ±1 px 精度限制（详见技术报告 §7.1 的 T30 说明）
- **超大载体较慢**：4000×3000 的手机照片若承载约 2500 个区块，嵌入 + 提取需要数十秒
  （本机实测 15~119 秒，手机上更久）。急着用就选 2048² 的生成载体，或改用"容量优先"档
